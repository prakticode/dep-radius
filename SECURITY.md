# Security

radius reads your source code locally and only sends package names and versions to the npm registry
and GitHub. Your code never leaves your machine.

## Reporting a vulnerability

Please do not open a public issue. Use
[GitHub's private vulnerability reporting](https://github.com/prakticode/dep-radius/security/advisories/new)
instead. You will get an answer within a few days.

Supported versions: the latest published release.
